# Principais comandos .NET Core no console
- Para saber a versão, igual é feito com *node.js*, *git* e *yarn*: `> dotnet --version
- Para saber quais *runtimes* estão instalados: `> dotnet --list-runtime`
- Para saber quais SDKs estão instalados: `> dotnet--list-sdks`
- Para restaurar uma aplicação corrompida ou com problemas nos pacotes (*Nuget* ou não), no diretório raiz da aplicação, faça: `> dotnet restore`
- Para fazer um _build_ (inclusive como complemento do comando anterior), no diretório raiz da aplicação, faça: `> dotnet build`
